# R-spatial-workflow-template

空间转录组相关补充代码素材模板。当前收录一份多组空间 CellChat 项目脚本：`cellchat/muti_group_cellchat_Spatial.R`。

该脚本保留原始项目路径、样本标签、颜色和 CellChat 参数，仅用于提取空间通讯分析思路。新项目应优先使用独立 CellChat 模板，再按空间对象类型补充坐标、spot size 和样本参数。

原始副本保存在 `../R-Python-bioinformatics-code-archive/legacy/original/09_spatial_related/`。

## 其他人员来源代码

`source_catalog/` 收录 385 份空间/Xenium R、R Markdown 与 Shell 语义副本；`SOURCE_CATALOG.tsv` 可按 spatial annotation、neighborhood、CellChat 等场景筛选。Shell 文件也保留在 Python Xenium 模板中，属于有意的跨语言共享副本。
